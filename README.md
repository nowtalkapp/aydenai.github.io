# Ayden — GitHub Pages

A black-and-white AI assistant landing/chat interface inspired by modern AI chat layouts.

## Deploy on GitHub Pages

1. Create a GitHub repository, for example `aydenai.github.io`.
2. Upload `index.html`, `styles.css`, and `script.js` to the repository root.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select your main branch and `/ (root)`.
6. Save and wait for GitHub Pages to publish the site.

The included chat is a frontend demo. It does not expose an API key or connect to an AI model. For a real AI backend, use a server/serverless function and keep the API key off the GitHub Pages frontend.
