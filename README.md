# Ayden

Minimal chat UI for GitHub Pages. Talks to any OpenAI-compatible API (Groq free tier recommended).

## Deploy

1. Upload `index.html`, `styles.css`, `script.js` to a GitHub repo root (or `/docs`).
2. Settings → Pages → Deploy from branch → root.
3. Open the site → **Settings** in the sidebar → paste a free Groq key → Save.

## Free key

- https://console.groq.com/keys  
- Defaults already set to `openai/gpt-oss-20b`

Key stays in the browser (localStorage) only. Never commit it.
